# ツクルAI Homepage

ツクルAI の紹介・ダウンロード用サイト（アプリ本体とは別フォルダ）。

## 見る

```bash
cd "/Users/nemaseiya/Desktop/ツクルAI-homepage"
npm start
```

ブラウザで http://localhost:4173 を開く。

## ダウンロードファイルを更新する

アプリ本体側で:

```bash
cd "/Users/nemaseiya/Desktop/ツクルAI"
npm run publish:desktop
```

成果物が `downloads/` にコピーされ、`manifest.json` が更新されます。
